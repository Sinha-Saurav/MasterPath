
# ASSIST2009 dataset and paper-comparison audit

## Uploaded dataset audit
File: `data/skill_builder_data.csv` (official Skill-builder variant uploaded by user)
- Rows: 525,534
- Binary correctness: 525,534
- Students: 4,217
- Distinct skill IDs: 123
- Original flag values: 1 -> 449,220; 0 -> 76,314
- Paper-reported ASSIST2009 benchmark: 325,637 interactions, 4,151 students, 26,688 questions, 123 knowledge points
- SHA-256 of exact uploaded file is recorded in DATASET_CHECKSUM.txt.

The raw release differs materially from the paper table (525,534 vs 325,637 interactions; 4,217 vs 4,151 students). Potential differences include row/attempt filtering, preprocessing version, and question granularity. `original==1` still yields 449,220 rows in this file, so that alone does not reproduce the paper count. A faithful data match needs identify and document the paper's exact filter recipe.

## Reference metric
Original DKVMN-KAPS paper reports ASSIST2009 AUC 0.8751 in its model comparison table. It is reference only, not reproduced result.

## Reproducibility
Training script defaults: 5 student-grouped folds; inner 15% student validation; Adam 0.001; max 100 epochs; batch size 256; dropout 0.2; CNN kernel 6, 3 hierarchical layers/residual blocks. `fold_metrics.csv` generated by a complete run is the actual model result. This archive has no full ASSIST2009 result because the complete training workload was not run in the authoring runtime.

## Smoke test (not the full benchmark)
A real-data subset run using 50 selected learners, 2 folds and 1 epoch completed end-to-end after the architecture refresh:
- Fold 1 AUC: 0.6104
- Fold 2 AUC: 0.6228
- Mean AUC: 0.6166
This only confirms that preprocessing/training/XGBoost/inference path executes on ASSIST2009 rows. It is undertrained and tiny subset; do not compare to full paper result.
